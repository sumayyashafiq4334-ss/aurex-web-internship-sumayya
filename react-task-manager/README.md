## Project Overview

The React Task Manager is a component-based task management web application developed as part of the AUREX Month 2 - Week 1 internship task.

The project was created using React and Vite to practice fundamental React concepts including JSX, functional components, props, state management, event handling, controlled inputs, dynamic list rendering, and localStorage.

## Technologies Used

* React
* Vite
* JavaScript
* JSX
* HTML5
* CSS3
* VS Code
* Git
* GitHub
* Browser LocalStorage

## Features

* Add new tasks
* Prevent empty tasks from being added
* Display tasks dynamically
* Mark tasks as completed
* Delete individual tasks
* Filter tasks by All, Active, and Completed
* Display total, active, and completed task counts
* Clear all completed tasks
* Save tasks using localStorage
* Maintain tasks after browser refresh
* Responsive design for mobile and desktop screens
